# M.V. Scholars Pre School website starter

## Run locally
1. Install Node.js (LTS).
2. Extract this project.
3. Open the project folder in VS Code.
4. In terminal run:
   ```bash
   npm install
   npm run dev
   ```
5. Open the local URL shown by Vite.

## Before publishing
- Replace the stock gallery and hero photos with real, school-approved photos.
- Confirm phone number, email, address, programs, timings, facilities, fee details and admission age with the school.
- The admission CTA currently opens WhatsApp for +91 87509 94677.
- Add the school's official logo if available.
- Deploy to Vercel: push to GitHub, import the repository in Vercel, and deploy.

## Notes
This is a frontend starter with no backend. Enquiries are directed to WhatsApp; it does not collect or store form data.
