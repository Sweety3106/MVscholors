## 🌟 About M. V. Scholars School

Established under the benevolent aegis of the **Manju Vijay Charitable Trust**, **M. V. Scholars School** is a nurturing, joyful, and value-centric educational institution situated in **Tikri Kalan, New Delhi**. 

We cater to young scholars aged **3 to 10 years** — from early childhood discovery in **Pre-Nursery and Kindergarten** through structured academic excellence in **Classes 1st to 5th**. 

Our educational philosophy blends foundational academic rigor with creative expression, moral virtues, active physical development, and compassionate individual care.

## 🎓 Academic Wings & Curriculum

M. V. Scholars School provides a thoughtfully designed curriculum tailored for children from ages 3 to 10 years:

### 1. 🧸 Kindergarten & Foundational Wing (Ages 3 – 5 Years)
*Activity-based, joyful early discovery:*
- **Pre-Nursery** — Sensory exploration, social bonding, and playful curiosity.
- **Nursery** — Language beginnings, motor skill refinement, rhymes, and visual storytelling.
- **LKG (Lower Kindergarten)** — Phonics, number recognition, cognitive play, and creative art.
- **UKG (Upper Kindergarten)** — Reading readiness, basic arithmetic, and self-confidence.

### 2. 📚 Primary School Wing (Ages 6 – 10 Years)
*Strong academic foundations, analytical reasoning, and personality growth:*

- **Class 4th**
- **Class 5th**

**Core Focus Areas:**
- 📖 Mathematics & Language Literacy (Hindi & English)

- 🎨 Art, Craft & Cultural Traditions
- 🏃 Physical Education, Yoga & Sports

## 🛡️ Campus Facilities & Child Safety

The school premises are crafted to ensure total safety, health, and holistic stimulation:

- 📹 **Safe & 24/7 CCTV Surveillance:** Comprehensive security cameras covering all classrooms, activity corridors, and entrance gates.
- 🎨 **Smart Activity Classrooms:** Child-friendly ergonomic furniture, interactive charts, audio-visual storytelling, and educational puzzles.
- 💧 **Multi-Stage RO Drinking Water & Hygiene:** Pure filtered drinking water and clean, child-height washroom facilities maintained round-the-clock.
- 🧩 **Dedicated Indoor & Outdoor Activity Areas:** Educational toys, building blocks, creative crafts, and active playtime.
- 🩺 **Medical First-Aid Readiness:** Stocked first-aid supplies and educators trained in prompt, caring response for any childhood bump or scrape.
- 🧘 **Morning Yoga & Value Assemblies:** Cultivating mindfulness, physical posture, respect, and patriotic values every morning.

## 💻 Website Tech Stack & Development

This modern, responsive single-page web application is built with:
- **Framework:** React 18 + Vite
- **Icons:** Lucide React
- **Animations:** Framer Motion
- **Typography:** DM Sans, Fredoka, Noto Sans Devanagari
- **Mobile Experience:** Custom sticky purple navigation drawer with responsive grid on desktop and swipeable horizontal carousels on mobile.

### Quick Start:

```bash
# 1. Clone the repository
git clone https://github.com/Sweety3106/MVscholors.git

# 2. Navigate to project directory
cd MVscholors

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev

# 5. Build for production
npm run build
```
